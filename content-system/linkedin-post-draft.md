Three weeks ago I asked Claude Code to write test cases for a demo banking app.

This week, it can run a whole team of helper agents while I keep working. 🧪

I've been learning Claude Code hands-on as a tester: Skills, subagents (helper AIs that take on part of a task), and generating test cases for the ParaBank demo app. Here's what just shipped, and how I see it from a QA seat:

🧩 Mods
Small scripts that customize Claude Code itself: your own panels, shortcuts and checks. I can picture a "run my regression checklist" button.

🔍 Code Review is now generally available
Available on Team & Enterprise plans. "/code-review ultra" sends several agents to review a branch in the cloud. As a tester, I'd still check what they flag. Reviewing the reviewer is part of the job.

🤖 Background subagents
In VS Code and the desktop app, helper agents research and test while I keep going.

⚡ Faster sessions
Cloud sessions start while you type, and the tool picks the right model more smartly in auto mode.

What I'm learning: the tools keep getting faster. Knowing what to delegate, and how to verify it, is becoming the most valuable skill a tester has.
